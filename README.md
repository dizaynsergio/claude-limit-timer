# ⏳ Claude Limit Timer

Мод для Claude, который держит 5-часовой лимит на виду:

- **Строка состояния под полем ввода:** `⏳ Лимит 5ч: 44% · сброс через 2ч 13м · неделя 13%`, обновляется каждые 30 секунд.
- **⏰ За час до сброса:** всплывающее сообщение и системное уведомление, один раз на окно.
- **✅ Когда лимит сбросился:** сообщение и уведомление, что можно снова работать на полную.

Цифры берутся из самого Claude (окна лимитов, которые сообщает каждый ответ). Никаких неофициальных запросов.

## Установка

В поле ввода сессии Claude Code в терминале:

```
/plugin install limit-timer --marketplace dizaynsergio/claude-limit-timer
```

Ответь `y` на добавление маркетплейса, затем Enter для области «user». Мод сразу заработает и будет загружаться в каждой новой сессии.

## Версия для браузера (claude.ai)

`userscript/claude-limit-timer.user.js` — скрипт для Tampermonkey. Показывает такую же плашку в правом нижнем углу claude.ai и присылает те же уведомления. Он опирается на внутренний запрос claude.ai, поэтому после обновлений сайта может сломаться. Тогда на плашке появится «⚠️ Нет данных о лимите».

## Разработка

```
claude plugin validate .
claude plugin test .
```

Настройки — в начале `hooks/register.ts`: `WARN_MS` (за сколько напоминать) и `TICK_MS` (как часто обновлять).
